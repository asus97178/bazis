# Глоссарий

Термины руководства, их имена в коде и где о них читать.

## Приложение и модули

| Термин | В коде | Что это |
| --- | --- | --- |
| Модуль | `@Module` | Единица приложения: свои сервисы, контроллеры, настройки; наружу — только `exports` ([Модули](../overview/modules.md)) |
| Корневой модуль | `AppModule` | Модуль, который передают в `runApp`; импортирует остальные |
| Глобальный модуль | `@Global()` | Его `exports` видны всем модулям без `imports` |
| Инкапсуляция | — | Правило видимости: модуль видит только свои сервисы и экспорты импортированных ([Инкапсуляция](../fundamentals/encapsulation.md)) |
| Пакет модулей | `bazis g pack` | Несколько модулей одной области в общей папке ([Архитектура модулей](../fundamentals/module-architecture.md)) |
| Паспорт модуля | `MODULE.md` | Описание модуля для людей и агентов: части, связи, правила |
| Ядро | `Kernel` | Запускает и останавливает приложение: настройки, контейнер, службы, хуки ([Приложение](../overview/application.md)) |
| Окружение | `BAZIS_ENV` | `development`, `test` или `production` |

## Внедрение зависимостей

| Термин | В коде | Что это |
| --- | --- | --- |
| Провайдер | `singleton(X)`, `scoped(X)` | Регистрация сервиса в модуле ([Провайдеры](../overview/providers.md)) |
| Время жизни | `singleton`, `scoped`, `transient` | Один на приложение, один на запрос или область, новый при каждом внедрении |
| Область | `ServiceScope`, `createScope()` | Время жизни scoped-сервисов: запрос или своя единица работы |
| Контракт | `abstract class IOrders` | Абстрактный класс, по которому внедряют реализацию; он же токен |
| Токен | `createToken<T>("Name")` | Ключ для значения или интерфейса, у которых нет класса во время выполнения |
| Граф сервисов | — | Все сервисы и их зависимости; проверяется при запуске ([Ошибки DI](errors/di.md)) |
| Захваченная зависимость | — | Singleton, зависящий от scoped-сервиса; запуск не пропускает |

## Кодогенерация

| Термин | В коде | Что это |
| --- | --- | --- |
| Кодогенерация | `bazis codegen` | Записывает зависимости конструкторов, привязку параметров и OpenAPI в `src/generated` ([Кодогенерация](../fundamentals/codegen.md)) |
| Цель | `targets` в `bazis.config.json` | Набор точек входа, для которого генерируется код |
| Точка входа | `entrypoints` | Файл, от которого кодогенерация собирает всё, что импортируется |

## HTTP

| Термин | В коде | Что это |
| --- | --- | --- |
| Контроллер | `@Controller` | Класс с маршрутами; создаётся на каждый запрос ([Контроллеры](../overview/controllers.md)) |
| Привязка параметров | — | Откуда берётся аргумент метода: путь, строка запроса, тело — по имени и типу |
| Модель запроса | `@RequestModel()` | Класс тела запроса с правилами `@Validator` ([Проверка данных](../overview/validation.md)) |
| Ограничение маршрута | `:id(int)` | Тип параметра пути; несовпадение — `404` |
| Middleware | `HttpMiddleware` | Функция вокруг обработки запроса ([Middleware](../overview/middleware.md)) |
| Фильтр действия | `@ActionFilter` | Код до и после метода контроллера |
| Проверка доступа | `@Authorize(check)`, `AuthorizeCheck` | Решает `401` или `403` до метода ([Авторизация](../overview/authorization.md)) |
| Кэш ответов | `@OutputCache` | Готовые ответы маршрута в кэше ([Кэш ответов](../http/output-cache.md)) |

## Запуск и работа

| Термин | В коде | Что это |
| --- | --- | --- |
| Хук жизненного цикла | `LifecycleHook`: `onInit`, `onShutdown` | Код при запуске и остановке ([Жизненный цикл](../fundamentals/lifecycle.md#хуки-жизненного-цикла)) |
| Фоновая служба | `BackgroundService`, `PeriodicBackgroundService` | Работа на всё время жизни приложения: очередь, расписание ([Фоновые службы](../realtime/background-services.md)) |
| Служба хоста | `HostedService` | Всё, что запускается и останавливается вместе с приложением: HTTP-сервер, подключения, фоновые службы |
| Фаза | `phase` | Порядок запуска служб: подключения раньше (меньше 0), HTTP — 10 |
| Плавная остановка | `shutdownTimeoutMs` | Доделать начатое и закрыть подключения по `SIGTERM` ([Плавная остановка](../deployment/graceful-shutdown.md)) |
| Экран запуска | — | Что запустилось или почему нет — в терминале ([Команды CLI](../cli/commands.md#экран-запуска)) |
| Шаг схемы | `BAZIS_SCHEMA_ONLY` | Запуск только ради схемы базы, до выкладки |

## Настройки и инфраструктура

| Термин | В коде | Что это |
| --- | --- | --- |
| Настройки | `defineConfig`, `ConfigView<T>` | Типизированные значения с окружениями и проверкой при запуске ([Конфигурация](../fundamentals/configuration.md)) |
| Секрет | `secret()`, `Secret` | Значение, которое не попадает в журнал и обязательно в `production` ([Секреты](../security/secrets.md)) |
| Манифест инфраструктуры | `@Infra` | Список подключений приложения ([Инфраструктура](../infra/overview.md)) |
| Коннектор | `postgres`, `redisConnect`, `llmConnect` | Подключение к базе, Redis, модели: настройки, клиент, здоровье |

## База данных

| Термин | В коде | Что это |
| --- | --- | --- |
| Контекст | `DbContext` | Единица работы с базой: отслеживает изменения, сохраняет их одной транзакцией ([DbContext](../database/dbcontext.md)) |
| Набор | `DbSet<T>` | Таблица в контексте: запросы и добавление |
| Сущность | `@Entity` | Класс строки таблицы ([Сущности](../database/entities.md)) |
| Отслеживание | `asNoTracking()` | Контекст помнит загруженные строки и сохраняет их изменения |
| Немедленные изменения | `executeUpdate`, `executeDelete`, `insertIfAbsent` | Один SQL-запрос сразу, без отслеживания ([Немедленные изменения](../database/immediate.md)) |
| Допуск схемы | `ensureCreated`, schema admission | Проверка и безопасное изменение схемы при запуске ([Схема](../database/schema.md)) |
| Собственное хранилище | owned store | Таблицы, которыми владеет пакет, с префиксом и записью о версии ([Собственные хранилища](../database/owned-stores.md)) |

## Реальное время и AI

| Термин | В коде | Что это |
| --- | --- | --- |
| Шлюз | `@WebSocketGateway` | Класс с обработчиками сообщений WebSocket ([WebSocket](../realtime/websocket.md)) |
| Комната | `socket.join(room)` | Группа подключений для рассылки |
| Агент | `AgentDataDefinition` | Инструкции и список инструментов; может жить в базе ([Агенты](../ai/agents.md)) |
| Инструмент | `@Tool` | Метод, который модель вызывает с аргументами по схеме ([Инструменты](../ai/tools.md)) |
| Побочный эффект | `sideEffect: "none" \| "read" \| "write" \| "external"` | Меняет ли инструмент данные или внешний мир; от него зависят аудит, подтверждение, повторы |
| Аудит | `auditSink` | Журнал вызовов инструментов с записью ([Хуки](../ai/hooks.md#аудит)) |
| Исход неизвестен | `…_OUTCOME_UNKNOWN` | Запись могла пройти, но подтвердить нельзя; без автоматического повтора ([Ошибки агентов](errors/agents.md#исход-неизвестен)) |
| Профиль модели | `modelProfile` | Имя модели в `llmRouter` ([LLM-коннекторы](../ai/llm-connectors.md)) |
