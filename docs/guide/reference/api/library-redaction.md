# `bazis/library/redaction`

Маскировка секретов в журнале и ошибках. Журнал и обработчик ошибок
bazis используют её сами ([Что маскируется в логах](../../security/secrets.md#что-маскируется-в-логах));
эти функции — для своего журнала или своего вывода. Список — по пакету
0.105.1.

| Экспорт | Что это |
| --- | --- |
| `redactSensitive(value)` | Копия объекта или ошибки со скрытыми секретами: по именам ключей, `password=`, `Bearer`, паролю в URL |
| `redactSensitiveText(text)` | То же для строки |
| `redactTraceValues(values)` | Заменить все значения списка заменителем — например, параметры SQL в трассировке |
| `isSensitiveKey(name)` | Похоже ли имя ключа на секрет: `password`, `token`, `apiKey`… |

Тип: `SensitiveRedactionOptions`.
